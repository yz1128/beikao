- 单选、判断：点完立即判分
- 多选：选完点「提交」，全对才算对
- 问答：先自己回想，点「看答案」再自评（忘了 / 模糊 / 记得）

答错或「忘了」进错题本，答对或「记得」移出。今日复习 = 未学卡 + 今天到期卡。

## 进度

进度存在浏览器本地（IndexedDB，降级 localStorage）。**换设备、换浏览器、移动文件都会丢进度**，走备份：

1. 「进度备份」→「导出进度」→ 复制那串 Base64
2. 新设备打开同一文件 →「进度备份」→ 粘贴 → 勾选「替换全部本机进度」→ 导入

导入是整体替换，不合并。
